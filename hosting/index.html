Matrix Widgets

Drawing games and a Linux terminal for your Matrix rooms.

In Element, use /addwidget with a widget URL below, then approve its permissions. Drawing games need a Matrix room; the Linux terminal also works on its own.

Doodle Phone

Write, draw, and guess as a story passes between players.

Sketch & Guess

Draw live while the room guesses. Requires a Matrix client and homeserver with LiveKit support.

Linux Terminal

A Linux machine in your browser, with a terminal, file transfers, top, and Snake. Files reset when the widget closes or restarts.
